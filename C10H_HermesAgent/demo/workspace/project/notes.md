# Hermes Agent 学习笔记

## 1. 学习闭环

Hermes 与普通聊天机器人的核心差别是「闭环」：一次任务结束后，后台 review 会把可复用的经验写进 memory 或 skill，下次会话开始时再注入系统提示。记忆是事实，技能是流程。

## 2. 跨会话记忆

MEMORY.md 存环境与经验，USER.md 存用户偏好，两者都有字符上限（2200 / 1375）。记忆只在会话开始时读取一次，所以「保存后要新开会话才能看到」。

## 3. 技能与工具

技能是 SKILL.md 形式的按需文档，通过 skills_list → skill_view 渐进加载。工具调用必须真实发生，小模型常见的问题是「口头声称已保存」但没有 tool_call。

## 4. 本地模型

Ollama 默认上下文只有 2048，Agent 需要 64k 级别；用 Modelfile 设置 num_ctx 后，4.6B 模型也能在 4GB 显存上跑工具调用。
