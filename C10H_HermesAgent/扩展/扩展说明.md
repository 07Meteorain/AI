> 挑战要求「完成个性化扩展」。这里不是改个名字，而是让 Hermes 在**人格、流程、上下文、工作流**四个层面适配这台机器和这个任务。
> 每个扩展都给出「改了什么 → 为什么 → 怎么验证」。

## 1. 人格扩展：SOUL.md 里的「阿赫」

**文件**：`E:\hermes\SOUL.md`（备份：`扩展/SOUL-阿赫.md`）

**改了什么**：在官方英文人格模板后追加中文身份与硬约束。

```markdown
## 身份：阿赫（A-He）

- 默认用简体中文回答；技术名词保留英文。
- 先给结论，再给证据和步骤。
- 涉及状态变更时必须真实调用工具，并附命令、路径或退出码；
  禁止声称"已保存/已执行"而没有工具调用记录。
- 不确定就直说，并给出验证方法；不编造版本号、路径或结果。
- 不把 API Key、token、密码写进回复或文件。
```

**为什么**：

- 官方模板是英文的，回答会中英混杂；
- demo 01 暴露了「幻觉写入」，所以把「必须真实调用工具」写进最高优先级的人格层，而不是只靠单次 prompt；
- 「先结论后细节」符合课程评审的阅读习惯。

**验证**：demo 02/03/04 的回复全部是中文、先结论；`hermes doctor` 显示 `SOUL.md exists (persona configured)`。

## 2. 流程扩展：自建技能 `c10h-delivery-check`

**来源**：demo 04 让 Hermes 用 `skill_manage` 真实创建（第一次缺 frontmatter 被回滚，第二次成功）。
**原始产物**：`证据/agent-created-skill.md`（4.6B 模型写的简版）。
**交付版**：`扩展/skill-c10h-delivery-check/SKILL.md`（补了 frontmatter、6 项检查的可验证动作、Pitfalls、验证脚本）。

**为什么**：

- 挑战的评分点里，「产物完整性」和「复盘质量」最容易漏项；
- 把检查清单做成技能，下次任何同类挑战都能 `/c10h-delivery-check` 一键加载，而不是每次重新想；
- 技能是「流程记忆」，比塞进 2,200 字符的 MEMORY.md 更合适。

**怎么用**：

```powershell
hermes chat -q "用 c10h-delivery-check 检查当前交付" -s c10h-delivery-check
# 或在交互会话里：/c10h-delivery-check
```

**验证**：

```powershell
hermes skills list | Select-String c10h
# │ c10h-delivery-check │ │ local │ local │ enabled │
```

## 3. 上下文扩展：64k 的本地模型

**文件**：`配置说明/配置模板/Modelfile`

```text
FROM gemma4:e2b
PARAMETER num_ctx 65536
PARAMETER temperature 0.6
```

**为什么**：

- Ollama 默认 2048，而 Hermes 的系统提示 + 工具 schema 起步 2–4 万 token；
- 不扩上下文，模型根本「看不见」完整工具说明，会乱调工具或直接聊天；
- 64k 是在 4 GB 显存下能稳住的档位（`ollama ps` 显示 100% GPU）。

**代价**：prefill 变慢（每轮 1–3 分钟）。这是硬件换来的，不是配置错误。

**验证**：

```powershell
ollama ps
# gemma4-e2b-64k  ...  100% GPU  65536
```

## 4. 工作流扩展：可验证的 demo 协议

**文件**：`demo/run_demo.ps1`、`demo/tools/render_transcript.py`、`demo/prompts/*.md`

这不是「写几个 prompt」，而是一套可复用的工作流：

1. **固定工具面**：每个场景用 `-t` 只给必要工具，避免模型乱选；
2. **强制验收**：prompt 要求回读文件 / 报告退出码；
3. **原始轨迹**：`--format stream-json` 落盘，保留每个 `tool_use` / `tool_result`；
4. **可读化**：渲染器把 JSONL 转成 Markdown，评审不用读 JSON；
5. **失败归档**：失败的 JSONL 单独保存（`证据/失败-01-幻觉写入.jsonl`）。

**验证**：

```powershell
cd demo
.\run_demo.ps1 -Scenario 01
# exit_code=0，transcripts/01_summary.md 含 4 次工具调用
```

## 5. 还没做的扩展（诚实边界）

| 扩展 | 为什么没做 | 怎么做（下一步） |
| --- | --- | --- |
| 消息平台（Telegram/飞书） | 没有 bot token，不应把他人凭据写进作业 | `hermes gateway setup` 选平台，填 token，`hermes gateway run` |
| 定时任务 | 没有消息平台，cron 结果无处投递 | `hermes cron` 创建每日检查任务，绑定 `c10h-delivery-check` 技能 |
| 外部记忆（Honcho/Mem0） | 需要额外服务/密钥 | `hermes memory setup` 选 provider |
| MCP 工具 | 本机没有要接的 MCP server | `hermes mcp add` |
| 桌面端 | 只用 CLI，未装 Electron 包 | `hermes desktop` |
