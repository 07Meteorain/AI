## 5. 哪些是真实的，哪些是边界

**真实执行**（有原始轨迹/文件/退出码）：

- Hermes 安装、配置、`doctor`、`gateway`、4 个 demo、记忆写入、技能创建；
- 所有版本号、commit、路径、日志均来自本机。

**未完成/未验证**（已在 README 与 AAR 标注）：

- Telegram/Discord/飞书等消息平台（无 token，未接入）；
- `hermes update`（GitHub API 403）；
- Docker 后端（本机无 Docker）；
- 云端模型（无 API key，全程本地 Ollama）。

**模型局限**（不掩盖）：

- demo 03 第一版把记忆路径答成 `E:\hermes\profiles\default\memories\`（实际是 `E:\hermes\memories\`），第二版在 prompt 允许「不确定」后如实回答「不确定」；
- 4.6B 模型在多步任务上会走弯路（demo 01 先用 `execute_code` 被拒）。
