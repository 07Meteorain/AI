## 1. L1 接口层

| 命令 | 期望输出 | 说明 |
| --- | --- | --- |
| `python -m brain` | 帮助文本，首行含「第二大脑」 | 无参数不报错 |
| `python -m brain version` | `brain 1.0.0` | — |
| `python -m brain ask "记一下 测试"` | 「回答 / 执行回执 / 记忆水位」三段 | 回执含意图、运行 id、步数、每步结果 |
| `python -m brain recall 不存在的东西` | 「没有命中。」+ 三条建议 | 不编造、不假装找到 |
| `python -m brain recall 打分规则 --json` | 合法 JSON（含 `run.intent`、`evidence`） | 全局开关可写在子命令后 |
| `python -m brain ask "x" --no-write` | 回执末行「只读模式：本次未写入记忆」 | 真的不写（退出后 `memory` 计数不变） |
| `python -m brain skill run 不存在` | 退出码 1，`✗` 与错误信息 | 失败必须是失败 |

**退出码约定**：`0` 正常；`1` 有检查未通过/操作失败；`2` 用户输入错误（如缺参数）；
`130` 被 Ctrl+C 中断（已完成部分已落盘）。

## 5. L5 记忆层

| 命令 | 期望 |
| --- | --- |
| `python -m brain capture "结论：先写测试再写实现" --layer K` | 写入 K 层，同时生成 `memory/knowledge/<id>.md` |
| `ls memory/knowledge` | 每条 K 记录一个 `.md` + `INDEX.md` |
| `python -m brain recall 先写测试` | 命中该 K 记录，显示分数与命中词 |
| `python -m brain recall 先写测试 --layer S` | 不命中（分层过滤生效） |
| `python -m brain promote` | 列出沉淀提议（或「没有需要沉淀的记录」） |
| `python -m brain promote --apply` | 落盘并在 `memory/db/evolution.jsonl` 之外的记录里体现 |
| `python -m unittest tests.test_memory -v` | 覆盖：四层写入、去重、层先验、同义词、镜像、更新、命中计数、回声过滤、四条沉淀规则 |

**索引一致性**：`python -m brain doctor` 的「KSTAR 索引一致」= 索引条数 == 记录总数。

## 6. 进化层

| 命令 | 期望 |
| --- | --- |
| `python -m brain evolve` | 「只看不改」；列出重复工作流、待生成草稿、同义词候选、沉淀提议；末行「本次落盘改动：0 处」 |
| `python -m brain evolve --apply` | 「已落盘」；`skills/_drafts/auto-*` 出现；`memory/db/evolution.jsonl` 追加 2–3 条 |
| `python -m brain review`（evolve 之后） | 1 步；说明「已固化的技能 … 接管」 |
| `python -m brain trend` | 按意图表里 review 的「变化」为负 |
| `python -m unittest tests.test_evolve -v` | 覆盖：阈值、单步排除、失败排除、别名候选（含 curated 词表回归）、脚手架可 import、dry-run 不落盘、周期幂等、趋势分组 |

**幂等性**：连续跑两次 `evolve --apply`，第二次不应再生成同名草稿
（第二次的输出应是「（没有达到阈值的重复工作流）」或不再新增 `auto-*` 目录）。

## 7. 模型适配（可选）

没有 API key 时的最低验收：

```bash
python -m unittest tests.test_llm -v
```

覆盖：JSON 提取（围栏/散文/垃圾）、未知工具丢弃、未知意图回落、无响应回落、
步数截断、模型回答被采用、空回答保留抽取式、降级标记。

有 key 时：

```bash
BRAIN_PROVIDER=openai BRAIN_API_KEY=sk-... python -m brain ask "上次那个检索排序怎么定的？"
```

期望：回答末尾出现「LLM 模式：回答由 … 生成；未经人工改写」。若失败，
回执仍应有答案（抽取式），并打印「降级原因」。

## 9. 已知不通过的情况（不是 bug，是设计）

| 现象 | 原因 |
| --- | --- |
| `python -m brain recall "上周那个事"` 没命中 | 词面匹配，无语义；换具体词或先 `capture` |
| `brain evolve` 从不再生成草稿 | 已有同 `tools` 序列的技能（去重生效） |
| 新库上 `brain trend` 说「样本少于 4 条」 | 拒绝在小样本上给结论 |
| `memory/db/traces/` 只有一个日期的文件 | 按天分文件，只有当天跑过 |
