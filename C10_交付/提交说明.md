## 五、评分维度自评（只写证据在哪，不写该给多少分）

### 系统架构（25）

- **分层清晰**：五层目录 + 依赖严格单向 + 唯一组合根 `brain/app.py`；`ARCHITECTURE.md` §2–3 给出契约表与不变量。
- **各层可工作**：`brain doctor` 七项逐层自检全绿；196 项测试按层分布（core / memory / tools+skills / loop+cli / evolve / llm）。
- **设计有据**：6 个 ADR 均含**被否方案与代价**（ADR-001 零依赖、ADR-002 纯 Python 索引、ADR-003 离线优先、ADR-004 JSONL、ADR-005 回声、ADR-006 草稿）。
- **脆弱点也写了**：§7 失败模式表 + §8 规模边界（>1 万条要换实现）。

### 记忆系统（20）

- **四层结构清晰**：K/S/T/AR，字段表、写入规矩、衰减策略在 `docs/KSTAR记忆规范.md` §1–2；A+R 合并的理由在 §0。
- **能沉淀**：`promote.py` 四条规则（任务完成→AR、流程重复→知识、重复错误→已知坑、冷情境→归档），演示中真的沉淀出 1 条「已验证流程」。
- **能检索**：BM25 × 层先验 × 重要度 × 新近度 × 使用次数（§3 有公式与理由）；演示中「打分规则」经同义词扩展命中知识层。
- **不只看设计**：`memory/` 里有 35 条真实记录、命中计数、同义词表、进化日志，可逐条打开看。

### 产物完整性（15）

- 14 条命令、12 个工具、3 个技能、196 项测试、演示脚本、10 份文档、CI workflow。
- **可独立使用**：零第三方依赖；`python -m brain doctor` 一条命令验证；README 有安装/使用/边界。
- 也交付了"运行后的状态"（`memory/`、`skills/_drafts/`），评审者不必先跑一遍才能看到进化结果。

### AI 使用质量（20）

- **多轮迭代**：11 轮记录（AI日志 §3），8 轮返工（F2–F8 + 分类器）。
- **prompt 优化**：`brain/llm/provider.py` 的两段 prompt 逐条说明"这条约束防的是什么"（AI日志 §4.1），并诚实标注**未在真实模型上 A/B**。
- **工作流设计**：开工前把一句话拆成 9 步可验收任务（AI日志 §2）；"数字必须可查"这条流程真的拦下两处夸大。
- **AI日志佐证**：F2–F8 每条都有"发现方式 + 修法 + 回归测试名"，可逐条核对测试是否存在。

### 复盘质量（20）

- **具体问题**：F1–F8 全部有现象、根因、修法、教训，没有"以后注意"。
- **含失败经验**：包括我自己写出的 5 个真 bug，以及"平均步数把结论说反"这种判断失误。
- **有改进方案**：AAR §5 的三条改法（先定 trace schema / 先想"什么不该进索引" / 度量先于功能）。
- **记录迭代过程**：时间线 + 首轮测试 `9 失败 1 错误` 的原始数字。
- **未解决项**：AAR §6 七条，含"只有 14 条 trace，趋势只能当示意"。

## 六、复现实验

```bash
cd C10_交付

# 1) 全量测试（零依赖）
python -m unittest discover -s tests

# 2) 逐层自检
python -m brain doctor

# 3) 重放演示（会清空并重建 memory/ 与 skills/_drafts/）
python demo/run_demo.py

# 4) 看进化证据
python -m brain metrics
python -m brain trend
cat memory/db/evolution.jsonl

# 5) 接真实模型（可选，需要 key）
BRAIN_PROVIDER=openai BRAIN_API_KEY=sk-... BRAIN_MODEL=gpt-4o-mini \
  python -m brain ask "上次那个检索排序是怎么定的？"
```

## 七、已知缺口（不藏）

1. 演示只有 14 条 trace，「进化趋势」是示意而非统计结论；
2. 无 API key，LLM 路径只在 `FakeProvider` 上测过，**没有真实模型跑通记录**；
3. 检索是词面匹配，没有语义（换说法找不到是常态，靠同义词缓解）；
4. 单进程写，无文件锁；
5. 草稿技能过度拟合时不会自动回滚，需要人工复审。

这五条在 README「诚实边界」与 AAR §6 各写了一遍——**重复写不是啰嗦，是怕有人只读一份文件。**
