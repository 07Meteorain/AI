## 课程简介

过去几年，大语言模型（LLM）为软件开发带来了一场范式层面的革命。传统软件开发生命周期的每一个环节都在被 AI 自动化重塑，这也随之提出了一个问题：下一代软件工程师应当如何利用这些进步，把自己的开发效率提升 10 倍，并为职业生涯做好准备？

本课程要说明，现代 AI 工具不仅能提升开发者效率，还能让软件工程惠及更广泛的人群。我们会展示，软件开发已经从「从 0 到 1 写代码」演进为「规划 → 用 AI 生成 → 修改 → 循环」的迭代式工作流。学生将同时掌握传统软件工程难题背后的原理，以及今天用于解决这些难题的前沿 AI 工具。

通过动手实践的工程任务，以及来自这些革命性工具一线建设者的行业分享，你将对 AI 辅助开发、自动化测试、智能文档生成和安全漏洞检测获得实战经验。课程结束时，你将清晰地理解如何把最先进的大语言模型（LLM）集成进复杂的开发工作流，并避开常见的坑。

## 常见问题

### 这门课适合谁？

本课程面向具备编程经验（相当于 CS111）的学生，帮助他们了解如何利用现代 AI 工具大幅提升自己的软件开发效率。建议修过 CS221/229，但不作强制要求。

### 这门课我会有什么产出？

学生将完成每周的动手作业，内容涵盖 LLM 提示词、MCP 服务器开发、AI IDE 使用、Claude Code 工作流、安全分析、代码评审自动化和全栈 Web 应用。课程最后以一个展示现代开发实践的最终项目收尾。

### 我们会用到哪些工具？

课程覆盖一批 AI 开发工具，包括 Claude Code、Warp 终端、Cursor/Windsurf IDE、Semgrep、Graphite 和 Vercel。我们还会用到 Model Context Protocol（MCP）以及各类 LLM API。

### 成绩怎么评定？

成绩由每周作业、课堂讨论参与度和最终项目共同决定。具体截止时间见作业日历。
