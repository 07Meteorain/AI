Claude Code 用于数据基础设施 数据基础设施团队为公司各团队组织所有业务数据。他们用 Claude Code 自动化日常数据工程任务、排查复杂的基础设施问题，并为技术和非技术团队成员建立有文档支撑的工作流，让他们能独立取用和处理数据。Claude Code 的主要用例 用截图排查 Kubernetes 问题 当 Kubernetes 集群宕机、不再调度新 pod 时，团队用 Claude Code 诊断问题。他们把仪表盘截图喂给 Claude Code，它逐层菜单地引导他们走完 Google Cloud 的界面，直到找到一条提示 pod IP 地址耗尽的警告。Claude Code 随后给出创建新 IP 池并将其加入集群的确切命令，完全不必惊动网络专家。 为财务团队准备纯文本工作流 团队教财务团队成员用纯文本文件描述自己的数据工作流，再把这些文件载入 Claude Code，获得全自动的执行。毫无编码经验的员工只要描述出诸如「查询这个仪表盘、获取信息、执行这些查询、输出 Excel」这样的步骤，Claude Code 就会执行整个工作流，包括主动询问日期这类必需输入。 帮新人熟悉代码库 新数据科学家加入团队时，会被引导使用 Claude Code 来探索他们庞大的代码库。Claude Code 会读取他们的 Claude.md 文件（文档），识别特定任务相关的文件，讲解数据流水线之间的依赖关系，并帮助新人理清哪些上游数据源汇入仪表盘。这取代了传统的数据目录和可发现性工具。 会话收尾时更新文档 团队要求 Claude Code 在每项任务结束时总结已完成的工作并提出改进建议。这形成了一个持续改进的循环：Claude Code 依据实际使用情况不断打磨 Claude.md 文档和工作流说明，让后续迭代更有效。 跨多个实例并行管理任务 处理耗时较长的数据任务时，他们会在不同仓库里为不同项目打开多个 Claude Code 实例。每个实例都保留完整上下文，因此几小时乃至几天后切回来时，Claude Code 仍记得他们当时在做什么、做到哪一步，从而实现真正无损上下文的并行工作流管理。 3 Claude Code 用于数据基础设施 Claude Code 用于数据基础设施 3 数据基础设施团队为公司各团队组织所有业务数据。他们用 Claude Code 自动化日常数据工程任务、排查复杂的基础设施问题，并为技术和非技术团队成员建立有文档支撑的工作流，让他们能独立取用和处理数据。 Claude Code 的主要用例 用截图排查 Kubernetes 问题 当 Kubernetes 集群宕机、不再调度新 pod 时，团队用 Claude Code 诊断问题。他们把仪表盘截图喂给 Claude Code，它逐层菜单地引导他们走完 Google Cloud 的界面，直到找到一条提示 pod IP 地址耗尽的警告。Claude Code 随后给出创建新 IP 池并将其加入集群的确切命令，完全不必惊动网络专家。 为财务团队准备纯文本工作流 团队教财务团队成员用纯文本文件描述自己的数据工作流，再把这些文件载入 Claude Code，获得全自动的执行。毫无编码经验的员工只要描述出诸如「查询这个仪表盘、获取信息、执行这些查询、输出 Excel」这样的步骤，Claude Code 就会执行整个工作流，包括主动询问日期这类必需输入。 帮新人熟悉代码库 新数据科学家加入团队时，会被引导使用 Claude Code 来探索他们庞大的代码库。Claude Code 会读取他们的 Claude.md 文件（文档），识别特定任务相关的文件，讲解数据流水线之间的依赖关系，并帮助新人理清哪些上游数据源汇入仪表盘。这取代了传统的数据目录和可发现性工具。 会话收尾时更新文档 团队要求 Claude Code 在每项任务结束时总结已完成的工作并提出改进建议。这形成了一个持续改进的循环：Claude Code 依据实际使用情况不断打磨 Claude.md 文档和工作流说明，让后续迭代更有效。 跨多个实例并行管理任务 处理耗时较长的数据任务时，他们会在不同仓库里为不同项目打开多个 Claude Code 实例。每个实例都保留完整上下文，因此几小时乃至几天后切回来时，Claude Code 仍记得他们当时在做什么、做到哪一步，从而实现真正无损上下文的并行工作流管理。 CLAUDE CODE 用于数据基础设施
