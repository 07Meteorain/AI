# Warp 与 Oz 快速上手

开始使用 Warp——智能体式开发环境，以及 Oz——面向云端智能体的编排平台。

Warp 是一个智能体式开发环境：把现代终端与强大的智能体结合起来，帮助你构建、测试、部署和调试代码。Warp 的 AI 由 Oz 这一面向云端智能体的编排平台驱动。

Warp 把现代终端与 Oz（面向云端智能体的编排平台）结合在一起

Warp

Warp 是你干活的地方——一个为「与智能体一起写代码」打造的迅捷现代终端。

核心能力：

智能体形态：在用于敲命令的干净终端与用于多轮智能体工作流的专用对话视图之间随时切换。

现代终端体验：光标移动、基于块的导航、多行编辑、语法高亮和丰富的补全。以 Rust 构建，性能拉满。

代码编辑器：文件树、支持 LSP 的代码编辑器，以及交互式的代码评审体验。

编码智能体集成：语音输入、@-选择等可直接处理终端内图片的功能。兼容 Oz，也兼容 Claude Code、Codex 这类智能体。

深入了解 Warp 的核心功能

Oz：面向云端智能体的编排平台

Oz 是面向云端智能体的编排平台，驱动着 Warp 的全部智能功能。Oz 的设计目标是大规模调度智能体——理解你的代码库、自主执行任务，并贴合你的工作流。Oz 在设计之初就是多模型的，让你能够为每项任务灵活挑选最合适的 LLM。

Oz 有两种运行模式：

本地智能体

直接跑在 Warp 应用里，提供实时、交互式的编码辅助。

在整个代码库中编写和重构代码

排查问题、修复错误

执行命令并解读结果

规划并执行多步任务

本地智能体让你始终掌握主动权：可以查看改动、在任务进行到一半时调整方向，并在动作执行前予以确认。

→ 开始使用本地智能体

云端智能体

Oz 云端智能体在 Warp 的基础设施（或你自己的基础设施）上于后台运行，实现大规模自动化。

触发器：响应来自 Slack、Linear、GitHub 或自定义 webhook 的事件

定时任务：执行依赖升级、死代码清理等周期性任务

并行：跨仓库或跨任务并发运行多个智能体

可观测性：每次运行都有记录、可审计、可分享给团队

云端智能体适合那些不必你即时盯着的工作，比如 PR 评审、issue 分派、日常维护，以及由集成事件驱动的工作流。

→ 了解云端智能体

二者如何协同

Warp 与 Oz 在本地和云端开发之间提供统一体验：

同一个智能体，随处可用：无论你是在 Warp 中以交互方式工作，还是在云端运行智能体，用的都是同一套底层智能体能力。

无缝接力：在云端起步的任务，你想亲手掌控时就在 Warp 本地接手，既不丢进度，也不丢上下文。

共享上下文：Warp Drive、Rules 和 MCP 服务器在本地与云端智能体中都能用，团队的知识和工具始终触手可及。

团队协作：共享智能体会话、评审智能体的动作、引导正在运行的任务，无论它们是谁发起的。

多模型支持

Oz 在设计之初就是多模型的。你可以从精选的一批顶尖模型中挑选自己偏好的 LLM。

隐私与安全

Warp 已通过 SOC 2 合规认证，并与所有签约的 LLM 供应商达成零数据保留（Zero Data Retention）政策。客户的 AI 数据不会被保留、存储，也不会用于训练。

Warp 的 AI 功能可在 Settings > AI 中全局关闭。
