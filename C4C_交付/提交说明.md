| 条件 | 验收方法 | 实测结果 |
|---|---|---|
| **可复用** | 在**全新目录**解压后运行（无任何本地环境依赖） | ✅ 在 `/tmp/verify` 干净解压，输出与开发时完全一致 |

| **IO 明确** | 能否一句话说清输入输出 | ✅ 输入=文献文件；输出=报告/修正bib/JSON/退出码 |

### 实测结果（真实运行，非模拟）

```
[FABRICATED] doe2021innovative   最佳匹配仅 0.52 < 阈值 0.82 → 编造
[FABRICATED] smith2023deep       最佳匹配仅 0.39 < 阈值 0.82 → 编造

```

**判定正确性**：4 条真实引用**零误报**（未被冤枉成假），2 条编造引用**零漏报**（全部抓出）。

## 四、环境要求（无任何第三方依赖）

| 项目 | 要求 |
|---|---|
| Python | ≥ 3.8（标准库即可，**无需 pip install**） |
| 网络 | 需访问 Crossref / arXiv / OpenAlex（均免费免密钥） |
| 离线场景 | `--offline` 降级为静态体检，不臆造结论 |

**为什么强调零依赖**：C4 的评判标准第一条是「**被使用次数**」。
一个需要 `pip install` 的技能，会在别人机器的第一步就卡住。
**用不起来 = 0 分**，所以依赖数是产品指标，不是工程细节。

## 五、已知局限（诚实声明）

| 局限 | 说明 |
|---|---|
| **无法判断引用是否支撑论点** | VERIFIED 仅代表"论文存在"，不代表你的引用恰当 |
| 中文文献覆盖差 | Crossref/OpenAlex 收录有限，需人工核查（当前明确短板） |
| 无 DOI 的会议论文可能漏检 | 会判为 UNCHECKED，需人工确认 |
| OpenAlex 年份可能是重印版本年份 | 已用 bib 年份作先验排序，并标注"版本漂移" |

> ⚠ **UNCHECKED ≠ 通过。** "没被证明是假的"与"已证明是真的"是两回事。
