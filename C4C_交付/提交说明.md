## 一、本次交付：作业自动求解与排版（homework-solver）

**位置**：[`homework-solver/`](./homework-solver/)

一条命令把作业文件转成可提交的 PDF 答案：
**md / pdf / docx / tex / 图片 → 摄入 → 解析 → 求解 → 验证 → LaTeX → PDF**

### 核心成果

| 测试集 | 本项目 | Claude starter kit 基线 |
|--------|--------|------------------------|
| Berkeley Math 1A WS3（切线 & ε-δ） | **8/8** = 100% | 8/8 = 100% |
| Berkeley Math 1A WS4（极限） | **10/10** = 100% | 9/10 = 90% |
| **核心域合计** | **18/18 = 100%** | 17/18 = 94.4% ✅ **超过** |
| 线性代数（新增学科） | **12/12** = 100% | 域外 |
| 物理 + 微分方程（新增学科） | **14/14** = 100% | 域外（40%） |
| **总计** | **44/44 = 100%** | — |

**每个答案都经过四层验证**（形式 / 数值代入 / 符号-数值交叉检验 / 量纲），
PDF 里直接标注 `✓ 已验证` 或 `⚠ 验证存疑`。

### 五分钟上手

```bash
cd homework-solver
pip install -r requirements.txt

# 跑示例（不需要 API Key）
python scripts/pipeline.py examples/homework_linear_algebra.md output/

# 真实作业 + 编译 PDF
python scripts/pipeline.py my_homework.pdf out/ \
    --compile --course "MATH 221 Linear Algebra" --student "你的名字"
```

**无需安装 LaTeX** —— 项目自带 `tools/tectonic.exe`，clone 即可编译。
