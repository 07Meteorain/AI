## 五、clone 后如何验证

本项目 **零第三方依赖**，clone 后无需 `pip install`：

```bash
git clone --depth 1 https://github.com/07Meteorain/AI.git
cd AI/C4D_交付/姓名_C4D_agent-skill

# 1. 验证纯逻辑（不需要模型）
python tests/test_offline.py            # 期望 38/38 passed

# 2. 验证地图渲染（不需要模型）
python -c "
import sys; sys.path.insert(0,'.')
from sias_local_agent.map_view import build_map_html, normalize_locations
locs = normalize_locations([{'name':'SIAS','name_zh':'西亚斯学院',
  'lat':34.4016,'lng':113.7361,'category':'校园'}])
print('归一化:', len(locs), '处')
print('HTML 长度:', len(build_map_html(locs)), '字符')
"

# 3. 验证本地推理（需要 Ollama + 模型）
ollama pull gemma4:e4b
python -m sias_local_agent.cli doctor
python -m sias_local_agent.cli run --task map --count 8
```

前两步在**任何装了Python 3.10+ 的机器上都能直接跑**，
不需要显卡、不需要网络、不需要模型。
