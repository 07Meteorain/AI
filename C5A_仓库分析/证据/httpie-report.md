- 提交统计使用 `git log` 的 committer date，工作区状态取 `git status --porcelain`。
- 行数为纯文本文件按 `\n` 计数的结果；含 NUL 字节的前 8KB 片段视为二进制并跳过行数。
- 测试文件按路径匹配 `tests/`、`test_*.py`、`*_test.go`、`*.test.js` 等常见约定。
- 变更热点按历史路径统计，不追踪 `git mv` 重命名，因此旧路径可能单独出现。
- 贡献者按 author name 去重，同一人的不同署名会被计为多人。
- 「过期远程分支」指超过 180 天未更新、且不是默认分支的 `origin/*` 分支。
- 健康度是启发式评分，只用于横向比较与发现缺口，不代表代码质量本身。
