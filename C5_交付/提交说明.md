## 一句话

`promptlint` 是一个**零依赖、离线、确定性**的 prompt 模板静态检查器：12 条规则、
81 项测试、文本/JSON/SARIF 三种报告、基线机制，用于在 prompt 进入模型之前拦住
「变量写错、密钥泄露、输出格式缺失、注入面暴露」这类机器可判定的问题。

## 一分钟验收

```bash
git clone https://github.com/07Meteorain/AI.git
cd AI/C5_交付

python -m promptlint check examples/good --fail-on info     # 期望：0 个问题，退出码 0
python -m promptlint check examples --config examples/promptlint.json  # 期望：12 个问题，退出码 1
python -m unittest discover -s tests                        # 期望：81 项通过
```

不需要 `pip install`。若想安装命令入口：`python -m pip install -e .`，然后
`promptlint --version`。

## 诚实边界

1. `promptlint` 检查的是**模板的机器可判定缺陷**，不评估 prompt 的实际效果；
   PL007/PL008/PL009 是启发式，存在误报，边界写在 `docs/rules.md`。
2. 本次交付**没有真实用户采用数据**；所有指标来自本仓库的示例、测试与 CI，
   不代表外部使用效果。
3. 演示配置把 `max_tokens` 调成 120 是为了在一屏内展示 PL010；默认值是 4000。
4. 仓库是课程 monorepo，GitHub 只运行根目录 `.github/workflows/`；因此真实 CI
   放在仓库根（`c5-promptlint.yml`），`C5_交付/.github/workflows/ci.yml` 是该项目
   独立成库时使用的版本。这一点在 README 与 CI 文件注释里都写明，没有假装它已运行。
