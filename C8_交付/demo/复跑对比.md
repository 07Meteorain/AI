## 五、不能直接横向比较的三处

1. **C6A / C9 / C10 是外部变更**：R1–R4 期间它们还没有交付目录，R5 才合并进来。
2. **C8 是本次交付**：R4 起把 `C8_交付/` 放进仓库，所以 C8 行从「无目录」变成 `100/100`
   —— **工具检查自己的交付**，这是刻意保留的 dogfooding。
3. **C7 只交了一半**：R5 里它 `1/3`（缺「文章标题」「数据截图」），所以 90/100 却仍是 FAIL ——
   这正是「红旗封顶」在起作用：维度分再高，缺必需交付物就不过门禁。

## 六、怎么复跑

```bash
cd C8_交付
python -m submitgate check --repo <仓库根> --out reports
python -m submitgate check --repo <仓库根> --out reports2   # 再跑一次
# 除 generated_at 外，两份 JSON 的 summary 应完全一致（已实测，见验收记录 §三）
python demo/验收检查.py                                      # 25 项产物自检
```
