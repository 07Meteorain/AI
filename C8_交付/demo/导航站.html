五、方法与边界

  • 只做文件级事实判断：文件名/路径匹配、字符与轮次统计、git 最后提交时间；不评价内容质量。
  • 匹配规则：平台写 *X* 按路径包含匹配；写 X.md 按文件名全等匹配。
  • 维度分是加权通过率，权重与证据都在「检查明细」里，可逐条反驳。
  • 不能自动验证的维度（如群内参与质量）标为「需人工」，不计 0 分、也不进分子分母。
  • 红旗照抄平台规则：命中即把对应维度封顶，不做加权稀释。
  • 按时交付只看 git 提交时间（clone 后文件 mtime 会被重置，不可信）。
  • 本页 PASS 只说明「该有的证据都在」，不说明「写得好」。
