**红旗项自查**：

- 核心交付物缺失？**否**——proposal / AAR_W / AI日志 均在，且代码可运行；

- 一句话指令直接提交、无迭代？**否**——16 处错误、3 版规格、128 项测试，全部有过程记录。

## 5. 一分钟验收

```bash
cd C9_交付

# 1) 不需要 pip install
python -m recall selfcheck
# 期望：10 个 PASS + SELF-CHECK OK

# 2) 全量测试
python -m unittest discover -s tests
# 期望：Ran 128 tests ... OK

# 3) 真实数据
python -m recall stats --db demo/c1.db --today 2026-11-15
# 期望：107 张（标题提问 56 / 填空 51）

# 4) 打开页面
python -m recall web --db demo/recall.db --out site
# 双击 site/index.html（或 file:// 打开）
```

浏览器自检（可选，需要 Edge/Chrome）：

```bash
msedge --headless=new --disable-gpu --virtual-time-budget=3000 \
  --dump-dom site/selftest.html | findstr data-result
# 期望：data-result="PASS"（120/120）
```

## 7. 复现环境

- Python 3.9+（实测 3.14.2）；无第三方包；
- 浏览器：任意现代浏览器（实测 Edge 143 headless）；
- 操作系统：实测 Windows 11；代码只使用 `pathlib` / `os.path` / `sqlite3`，未调用平台专有 API
  （`os.startfile` 仅在 `web --open` 时使用，其他平台会提示手动打开）。
